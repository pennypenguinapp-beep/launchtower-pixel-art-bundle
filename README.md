# LaunchTower Free Pixel Art Bundle

**48 free pixel art tiles** across 3 themed packs — Autumn Forest, Dungeon, and Winter Forest.

- 128×128 px RGBA PNG tiles (scales cleanly to 16×16 style)
- 8-color palette per pack
- 4×4 contact sheet per pack
- **CC0 1.0 Public Domain** — free for commercial use, no attribution required

## What's inside

| Pack | Tiles | Theme |
|---|---|---|
| 🍂 Autumn Forest | 16 | grass, oak & pine trees, water, campfire, bridge, signpost, fence, mushrooms |
| 🏰 Dungeon | 16 | stone walls, torches, mossy bricks, chest (open & closed), trap spikes, potions, well, cobweb, pillar, door |
| ❄️ Winter Forest | 16 | snowy variant of the autumn set — same shapes, cold palette |
